TCP Specification

Background, evolution, purpose, and scope of the updated Transmission Control Protocol specification.

Background Specification Evolution Purpose Scope Implementation Use

Background

In 1981, RFC 793 was released. It documented the Transmission Control Protocol (TCP) and replaced earlier published TCP specifications.

Since then, TCP has been widely implemented. It has been used as a transport protocol for many applications on the Internet.

Key point: TCP became a common transport protocol for Internet applications and has been implemented for several decades.

Specification Evolution

For several decades, RFC 793 and several other documents served together as the core specification for TCP. See RFC 7414 for additional historical context.

Over time, several errata were filed against RFC 793. Deficiencies were also found and resolved in security, performance, and other areas.

The number of TCP enhancements increased over time. These enhancements were described in many separate documents. They were not collected into one comprehensive update of the base specification.

Purpose of This Document

The purpose of this document is to collect the IETF Standards Track changes and other clarifications made to the base TCP functional specification in RFC 793.

The document unifies these changes into an updated version of the TCP specification.

  • Collect updates that affect the base TCP functional specification.
  • Include relevant Standards Track changes and clarifications.
  • Provide one updated specification for common TCP behavior.
  • Support conformance checking of existing TCP implementations.
  • Support development of new TCP implementations.

Scope and Companion Documents

Some companion documents are referenced for important algorithms used by TCP. Congestion control is one example.

These algorithms are not completely included in this document. This is intentional. The base TCP specification can be used with multiple additional algorithms that may be developed and incorporated separately.

This document focuses on the common basis that all TCP implementations must support to interoperate.

Design principle: The base specification defines common TCP behavior, while more advanced algorithms and features can be specified separately.

Some additional TCP features have become complex. Advanced loss recovery and congestion control are examples. Future companion documents may collect and unify these areas in a similar way.

Protocol Specification and Intended Use

The TCP specification describes the segment format, generation rules, and processing rules that must be implemented in code.

RFC 793 and other TCP updates also contain informative and descriptive text. This text helps readers understand the protocol design and operation.

This document does not attempt to change or update that informative text. Its focus is the normative protocol specification.

References to important documentation are preserved where appropriate. These references provide additional explanations and design rationale.

Intended use: This document is useful for checking existing TCP implementations for conformance and for developing new implementations.
