Section 3.3

TCP Terminology Overview

This section introduces the key terms needed to understand the detailed TCP protocol operation. A glossary is provided in Section 4.

Section 3.3.1

Key Connection State Variables

TCP maintains state for several variables during a connection. These variables are stored in a Transmission Control Block (TCB).

The TCB includes local and remote IP addresses and port numbers, the IP security level and compartment, pointers to user send and receive buffers, pointers to the retransmit queue and current segment, and variables related to send and receive sequence numbers.

Section 3.3.2

State Machine Overview

A TCP connection moves through a series of states during its lifetime. The states are LISTEN, SYN-SENT, SYN-RECEIVED, ESTABLISHED, FIN-WAIT-1, FIN-WAIT-2, CLOSE-WAIT, CLOSING, LAST-ACK, TIME-WAIT, and the fictional state CLOSED.

01

LISTEN

Waits for a connection request from a remote TCP peer and port.

02

SYN-SENT

Waits for a matching connection request after sending a connection request.

03

SYN-RECEIVED

Waits for a confirming acknowledgment after receiving and sending a connection request.

04

ESTABLISHED

An open connection. Received data can be delivered to the user. This is the normal data-transfer state.

05

FIN-WAIT-1

Waits for a termination request from the remote peer or an acknowledgment of the local termination request.

06

FIN-WAIT-2

Waits for a termination request from the remote peer.

07

CLOSE-WAIT

Waits for a termination request from the local user.

08

CLOSING

Waits for an acknowledgment of the termination request from the remote peer.

09

LAST-ACK

Waits for an acknowledgment of the termination request already sent to the remote peer.

10

TIME-WAIT

Waits long enough to confirm that the peer received the acknowledgment and to prevent delayed segments from affecting a new connection.

11

CLOSED

No connection state. There is no TCB and therefore no connection.

Connection Events

What Causes State Changes?

A TCP connection moves from one state to another in response to events such as:

  • User calls: OPEN, SEND, RECEIVE, CLOSE, ABORT, and STATUS.
  • Incoming segments, especially those containing SYN, ACK, RST, and FIN flags.
  • Timeouts.
OPEN behavior: An active OPEN attempts to start a connection. A passive OPEN waits for incoming connection requests.

Notes and Exceptions

Note 1

The transition from SYN-RECEIVED to LISTEN after receiving a RST is conditional. It applies when SYN-RECEIVED was reached after a passive OPEN.

Note 2

The figure omits the transition from FIN-WAIT-1 to TIME-WAIT when a FIN is received and the local FIN is also acknowledged.

Note 3

A RST can be sent from any state with a corresponding transition to TIME-WAIT. These transitions are not shown because they would make the diagram difficult to read. Receipt of a RST from any state results in a transition to LISTEN or CLOSED; these transitions are also omitted for legibility.
